# LP 기본 명단 정리 기준과 1차 결과

후속: 9월11일 금융기관 대조로132개 관리대상으로 확장했다. 아래62개는 1차 시점 수치다. 최신 결과는 `docs/lp_directory_progress_2026-09-11.md`.

2026-09-10 사용자 결정: 공고 복원보다 법적 유형에 따른 LP 기본 명단을 먼저 정리한다.
기존 공고 83개 전량 복원은 보류한다. 기존 기관 입력·운영 DB·공개 사이트는 이번에 바꾸지 않았다.

## 명단

`data/lp_directory_review.json`은 운영 입력과 분리된 검토 명단이다.
기존 52개를 모두 보존하고, 현행 법령에서 명칭·유형을 대조한 10개를 추가했다.
추가: 대한민국, 한국은행, 농업협동조합중앙회, 산림조합중앙회, 예금보험공사,
한국주택금융공사, 한국금융투자협회, 한국예탁결제원, 한국거래소, 금융감독원.
협회·예탁결제원·거래소는 법상 정의 및 현행 법인 동일성 추가 확인 대상으로 명시했다.

62개는 관리 대상 수다. 법률상 모든 적격 LP 수, 실제 출자 LP 수, 검수 완료 기관 수가 아니다.
기존의 법적 근거는 그대로 신뢰하지 않았고, 개별 설립법·인가등록·조건 충족을 추가 확인하도록 했다.

- 법정기금·관리법인 경로 후보 21개
- 법률상 공제사업 법인 경로 후보 7개
- 금융기관 경로 8개
- 법령 명시 기관 경로 10개
- 국가·한국은행 2개
- 개별 법적 경로 확인 필요 14개

기관뿐 아니라 기금·특별회계가 섞여 있으므로 이를 전부 기관 수로 부르지 않는다.
기관, 자금, 공고를 운영하는 기관, 실제 출자 계약 당사자를 구분하고 관계로 연결해야 한다.

법정 유형 전체의 범위와 명단의 수집 범위는 별개다. 금융기관, 법정기금·공제법인,
지자체, 조건부 상장법인·일반법인·재단, 투자기구, 외국 투자자, GP 관련자 등을
별도의 경로로 관리한다. 단순히 전문투자자라는 이유로 기관전용 LP 적격을 인정하지 않는다.
제5항 제6호의 위임 고시 상세 대조는 남아 있다. 예외적 개인 자격은 기관 명부와 분리한다.

## 분리해서 관리할 항목

1. 주체 식별: 정식 명칭, 법인·기금 구분, 설립 근거, 인가등록 식별자, 이름 변경.
2. 참여 자격: 적용 조문, 개별 충족 근거, 확인일, 요건 유효기간.
3. 출자 활동: 모집·선정·약정·납입 구분, 투자기구 종류, 원문, 기준일.
4. 역할: 자기자금 출자, 기금 관리, 수탁 운용, 공고 운영을 관계별로 기록.
5. 서비스 공개: 검수 상태와 공개 여부. 공고 미발견이나 OCIO라는 이유만으로 기본 명단에서 제외하지 않음.

기존 `coverage_tier`, `display_enabled`는 종전 상태 확인용으로만 보존했다.
법적 자격이나 새 공개 결정을 의미하지 않는다. 공고를 낸 사실과 실제 납입을 구분하며,
벤처펀드 활동을 곧바로 기관전용 PEF 출자 이력으로 바꾸지 않는다.

## 발견된 문제와 처리

- 기존 법적 분류에 OCIO(운용 방식), 후보(서비스 상태), 정책펀드 운영기관(역할)이 섞임:
  새 검토 명단에서는 자격 경로와 검수 메모를 분리했다.
- 수협중앙회와 수협은행의 별칭 혼합: 기존 별칭을 새 명단에 승계하지 않았다.
- 근로복지공단과 고용보험·산재보험기금의 별칭 혼합: 별개 주체를 보존하고 관리관계 검토로 남겼다.
- 환경개선특별회계: 기금 자격을 자동 적용하지 않았다.
- 정책펀드 운영기관과 개별 펀드의 LP 지위: 운영기관이라는 사유만으로 자격을 확정하지 않았다.

## 명단 확장 순서

1. 금융기관은 감독기관·협회의 공식 인가등록 명부와 대조해 은행·보험·금융투자·여전·저축은행·금융지주 등을 채운다.
2. 법정기금과 공제법인은 공식 기금 명부와 설립법으로 채우고 관리기관과 연결한다.
3. 지자체 명단을 추가하고 산하기관은 별도 주체로 검토한다.
4. 조건부 법인·재단·상장법인·해외 투자자 등은 요건 근거가 확보된 범위에서 추가한다.

검수: 기존 52개 코드 누락 없음, 전체 62개 코드 유일, 모든 법적 경로 참조 유효.
운영 입력을 읽는 수집기·DB 스키마는 수정하지 않았으며, 데이터 검토본과 문서만 추가했다.
