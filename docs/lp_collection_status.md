# LP 공고 수집 구축 현황

현황 정리: 2026-10-19. 기관별 구축 범위를 확인하는 기준 문서다. 작업 완료 시 해당 행을 갱신하며, 기본 현황 질문에 답하기 위해 코드를 다시 조사하지 않는다. 마지막 실행 결과는 아래에 별도로 기록하고 항상 시점을 붙인다.

## 현재 요약

- 수집 목표 16기관: 기관별 수집을 우선 구축한 4곳, 일부 경로를 연결한 8곳, 전용 수집 미연결 4곳.
- 추가 확인 대상 8기관은 아래에서 별도 관리한다. 추가 확인 대상이라는 이유로 공고가 없는 기관이라고 단정하지 않는다.
- 4곳을 우선 구축했다는 것은 신규 사업 자동 공개까지 완료했다는 뜻이 아니다.
- LP 앱은 [독립 Vercel 서비스](https://kpef-lp.vercel.app/)로 운영한다. 서비스 분리와 수집 완성은 별개다.

## 마지막으로 확인한 실행 결과

- 확인 대상: [2026-10-19 예약 실행 39201843668](https://github.com/pkkong/korea-pef-db/actions/runs/39201843668). 전체 결과는 실패다.
- 수집된 자료와 기존 공개 사업 17개의 발행·사이트 응답 확인은 성공했다. 공개 실행 식별자는 `e12fc7f543332c409080dc00`이다.
- 금투협 안내사항 게시판(`kofia_212`)이 불완전한 목록 HTML을 반환해 마지막 장애 보고 단계에서 실패했다. 이전 자료를 보존했다고 해서 이번 수집 전체를 성공으로 표시하지 않는다.
- 한국성장금융 3개 사업, 우정 국내 PE 사업, 수출입은행 하반기 사업은 새 후속 공고 연결을 보류했다. 교직원공제회 수집에는 보류가 없었다. 접속 장애와 새 자료의 연결 보류를 구분한다.
- 발행본의 공통 보존 자료는 11기관 27본문·기관 원문 15건·정리된 모집정보 4건이다. 당일 모두 새로 수집했다는 뜻이 아니며, 기관별 구축 완료 지표로 합산하지 않는다.
- 예약 설정은 평일 09:20·15:20이며 실제 실행 시각은 지연될 수 있다. 이 문서가 이후 실행의 성공 여부까지 보증하지 않는다.

## 다음 작업 순서

1. 금투협 불완전 응답의 복구·검증과 기본 공고 자동 공개를 운영 반영한다. 아래 로컬 구현 기록과 운영 완료를 구분한다.
2. 기관별 실제 반영 결과와 남은 후속 공고 보류를 확인한다. GP 프로필 연결은 미룬다.
3. 미연결 기관의 공식 수집 경로를 확장하고, 실제 발견·발행까지 확인한 뒤 해당 행을 갱신한다.

## 갱신 규칙과 근거

- 서비스 담당자가 소스 변경·운영 반영 후 영향받은 기관의 구축 범위와 남은 작업을 함께 갱신한다. 로컬 구현과 운영 적용을 구분한다.
- 일상적인 구축 현황 답변은 이 문서가 기준이다. 최신 장애·정상 실행 질문은 필요한 실행만 추가 확인한다. 모르는 상태는 미확인으로 남긴다.
- 범위와 수집 정책: [수집 범위 문서](lp_contest_collection_scope.md), `data/lp_blind_contest_scope.json`.
- 배포·검증 이력: [프로젝트 상태판](project_lead_control_center.md).
- 실행·첨부 판독·기관 연결의 상세 근거는 기존 수집 보고서와 관련 테스트에서 확인한다. 이 문서를 만들기 위해 수집이나 DB 발행을 다시 실행하지 않았다.

## 이번 구현 — 운영 적용 전

- 사용자 승인으로 공식 국내 PE 블라인드 모집 확인과 모집조건 전체 판독을 분리했다. 기본 공고는 원문·기관·제목·공고일로 공개하고 마감·금액·주목적은 확인된 값만 추가한다. 혼합 모집은 PE 트랙이 분리 검증된 경우만 공개한다.
- 기존 사업 주소와 자료를 보존하며, 확인된 후속 단계는 GP 명단 없이도 연결한다. 공고번호·평가 1차를 사업 차수로 오인하지 않고 재공고는 별도 모집으로 유지한다. 변경·취소 시 이전 마감과 예정 일정을 현재 정보로 남기지 않는다.
- 금투협 HTTP 200 불완전 HTML도 기존 제한 재시도/복구 경로에서 검사한다. 실제 안내사항 3페이지·30목록 수신을 확인했다. 계속 불완전하면 실패를 알린다.
- 대상 소스는 이미 연결된 기관 전체다. 미연결 기관의 새 수집기를 추가한 작업은 아니다. 아래 운영 검증 기록이 생기기 전까지 기관별 구축 표의 운영 범위는 그대로 유지한다.
