# Design System

## Principle

The service should feel like a modern market brief, not a promotional landing page.

- Use a restrained palette: white background, white surfaces, black text, neutral gray secondary text.
- Avoid bright accent colors unless they encode status.
- Typography should be consistent across public dashboard, newsletter, and future detail pages.
- Prefer clear data entry points over explanatory marketing copy.
- Use thin borders and whitespace before shadows, gradients, or decorative shapes.

## Tokens

- Background: `#ffffff`
- Paper: `#ffffff`
- Primary text: `#171717`
- Secondary text: `#737373`
- Border: `#e5e5e5`
- Strong border: `#d4d4d4`

## Typography

- Font stack: `Pretendard`, `Pretendard Variable`, `Noto Sans KR`, `Apple SD Gothic Neo`, `Malgun Gothic`, `system-ui`, `sans-serif`
- Page title: 28-34px on mobile, up to 40px on desktop
- Section title: 20-28px
- Body and metadata: 12-14px
- Letter spacing: only small negative tracking for large Korean headings

## Layout

- Mobile first.
- Public service width: 760-880px unless a table-heavy admin view needs more.
- Public dashboard views are separated into home, market, GP, and compare.
- Cards use the same radius, border, and padding rules.
- Newsletter sections use the same paper surface and border language as the public dashboard.
