# LP 첫 공개 완료 기준

2026-10-21. 기관을 계속 추가하느라 공개가 끝없이 미뤄지지 않도록 첫 공개의 끝을 정한다. 현재 운영 주소는 https://kpef-lp.vercel.app/ 이며, 사이트 접속 가능과 수집 안정화·정식 공개 완료는 구분한다.

## 첫 공개 범위

- 공식 국내 PE 블라인드 공모 근거를 확보한 17기관을 현재 수집 대상으로 고정한다. 명단은 `data/lp_blind_contest_scope.json`, 실제 기관별 연결 수준은 `docs/lp_collection_status.md`를 따른다.
- 직접 운영 수집 9기관, 협회 발견·기관 원문 연결 중심 8기관을 구분한다. 새마을금고는 서울 전송기로 운영 수집·공개를 확인했다. 부분 연결이나 로컬 구현을 전용 운영 수집 완성으로 부르지 않는다.
- 추가 확인 7기관은 근거와 남은 확인을 기록한다. 미확인을 미공모로 단정하지 않으며, 확인되지 않은 사업을 공개하지 않는다. 산업·기업은행은 공식 목록·본문·첨부를 자동 수집하되 PE 블라인드 및 PE 전용 배정 확인 전에는 공개하지 않는다.
- 신규 자료가 현재 범위의 결함을 보여주면 바로잡되, 새 기관 추가·과거 전수 복원 자체를 매번 새로운 출시 선행조건으로 만들지 않는다.

## 장애 판단
