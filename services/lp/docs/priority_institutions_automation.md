# 우정사업본부·교직원공제회·수출입은행 PE 출자사업 운영

2026-10-07 기준. 기존 한국성장금융과 같은 `services/lp/src/lp_program_service.py` 사업·일정·단계별 GP 화면 및 Supabase 공개 읽기 모델을 사용한다. 로그인 없이 `/admin/lp`에서 공개 원문과 새 단계 연결 후보를 읽는다.

## 수집·공개 경로

- `.github/workflows/collect-kgrowth-programs.yml`이 평일 09:20·15:20 KST에 한국성장금융과 아래 세 기관을 수집한다. GitHub 예약 실행은 정시를 보장하지 않는다.
- 수출입은행 공식 사이트는 GitHub의 Ubuntu 실행 서버에 공고 대신 차단 화면을 반환한다. 우정사업본부 사이트도 같은 서버에서 반복적인 응답 지연이 확인됐다. 따라서 두 기관은 각각 macOS 실행 서버에서 원문·첨부를 수집하고, 그 실행의 증거 파일만 Ubuntu 게시 작업에 전달한다. 파일이 누락되거나 2시간 이상 오래되면 해당 기관의 수집 실패로 처리하며 기존 공개본을 유지한다.
- `collect_priority_lp_programs.py`가 기관별 수집 결과를 합친다. 각 수집기는 원문과 핵심 첨부의 SHA-256을 검토 기록과 대조하고 사업·일정·GP 명단을 다시 계산한다. `publish_lp_programs.py`는 수집기의 `programs` 필드를 공개 허가로 신뢰하지 않고 원문에서 재투영한다.
- 새 단계/정정/결과 공고는 `/admin/lp`에 사업 연결 후보로만 표시한다. 원문·첨부 변경이나 GP 명단 불일치는 해당 사업의 마지막 정상 공개본을 유지한다. 출처 장애는 다른 기관의 공개를 지우지 않되 workflow를 실패로 표시한다.
- 기존 검토 사업은 원문/첨부 해시를 대조해 반복 발행한다. 신규 PE 전용 단일 분야 사업은 `lp_notice_terms.py`의 공통 항목·표 규칙으로 출자액, 선정 수, 마감, 주목적을 추출해 게시한다. GP 명단 및 프로필 연결은 이번 자동화 범위에서 제외한다.

## 새 공고 발견

- 이 단계의 우선순위는 GP 프로필 연결이 아니라 공식 출자공고의 누락 방지다. 새 공고는 기존 사업에 자동으로 붙이지 않고 `/admin/lp`의 `새 출자공고 후보`에서 원문을 확인한다. PE에 해당하는지 확인하기 전에는 공개 사업 목록에 추가하지 않는다.
- 교직원공제회는 `PEF`와 `블라인드` 제목 검색을 끝 페이지까지 확인한다. VC 제목은 PE 후보에서 제외하며, 2027년처럼 다른 연도의 PEF 공고는 2026년 사업의 후속으로 처리하지 않는다.
- 우정사업본부는 국내 블라인드 PEF 외에도 `사모펀드`, `사모투자`, `공동투자전략` 제목을 공식 게시판에서 찾는다. 현재 목록이 최근 20건만 보여 2026년 모집 원공고 347·348번은 빠져 있었지만 개별 공식 주소에는 남아 있었다. 수집기는 목록의 가장 오래된 번호부터 2025년 경계까지 제한적으로 역탐색하며, 347→349→351 및 348→350→352를 제목의 전략·연도와 단계로 묶는다. 351·352는 우선협상대상자이지 최종 선정이 아니다.
- 수출입은행은 공식 게시판의 2026년 펀드 공고를 수집해 기존 세 사업과 대조한다. 현재 기존 사업에 속하지 않는 공고 4건이 발견됐으며, VC나 다른 정책사업일 수 있어 PE 여부를 검토해야 한다.
- 한 번 발견한 공식 공고는 게시판에서 밀려나거나 수집이 일시 실패해도 검토 기록에서 사라지지 않는다. 새 원문이 확인되면 같은 URL의 기록을 갱신하며, 검토 완료 전까지 원문 링크를 보존한다.
- 새 공고의 PE/VC 범위는 모집 원공고의 펀드 법적 형태를 읽어 자동 분류한다. 일반 텍스트 추출이 불가능한 수출입은행 PDF 첫 장은 macOS 문자 인식으로 읽고, 인식 실패나 원공고 부재는 `범위 미확인`으로 유지한다. VC 전용 공고나 PE·PD 투자관리 위탁을 기관전용 PE 출자사업으로 자동 공개하지 않는다. 공고 ID를 사람이 후보 목록에 입력해 확장하는 방식은 사용하지 않는다.

## 신규 사업 조건 추출·공동사업 원공고 수집 (2026-10-07)

- `lp_notice_terms.py`는 기관·연도·사업명에서 사업 ID를 계산한다. 개별 공고 ID나 값의 승인 목록을 추가하지 않는다. 공식 본문 항목과 단일 분야 PDF 표에서 출자규모·선정 수·마감·주목적을 읽고 각 값의 원문 인용, 출처, 문서 지문을 남긴다.
- 필수 항목이 없거나 값이 충돌하는 경우, 표 숫자가 붙어 열을 구분하지 못하는 경우, 다중 분야, 변경·취소 공고가 있는 경우는 보류한다. 새 공고는 추정해 게시하지 않으며 기존 자동 게시 사업은 마지막 정상 공개본을 유지한다. PE·VC 혼합형과 투자관리 위탁은 이번 단일 분야 PE 게시 규칙의 대상이 아니다.
- 우정사업본부 국내 공동투자 전략: 2,000억원 이내·1개사·4월 6일 15시 마감. 3월 23일 모집, 4월 13일 1차 심사, 4월 21일 우선협상대상자 공고를 묶는다. 우선협상대상자를 최종 선정으로 바꾸지 않는다.
- 임상3상 특화펀드: 모태펀드 700억원 이내, 수출입은행·기업은행 각각 100억원 출자 계획을 구분한다. 공동 출자 총액은 900억원 이내(예정), 결성 목표 1,500억원, 선정 1개사, 6월 5일 14시 마감이다. `commitment_amount_krw`는 수출입은행의 100억원, `total_commitment_amount_krw`는 공동 총액이며 공동출자자별 승인 완료를 추정하지 않는다.
