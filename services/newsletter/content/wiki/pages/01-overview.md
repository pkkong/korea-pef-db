# 기관전용 사모집합투자기구 개요

이 파일은 현재 공개 화면의 내용을 바로 바꾸지 않는 markdown 이관용 골격입니다.
본문 이관 시에는 기존 `pef_wiki_pages.py`의 문단과 내부 링크를 기준으로 옮기고, 각 문단에는 `source_refs`와 필요한 조문 참조를 연결합니다.

## 이관 원칙

- PDF 원문은 출처로만 관리하고, 공개 페이지는 문서형 위키 본문으로 구성합니다.
- 내부 이동은 섹션 앵커와 용어 앵커를 사용합니다.
- 법률, 보고, 세무, 체크리스트 문서는 각각 독립 markdown으로 확장합니다.
- 공개 문구에는 운영 상태, 작성자 메모, 자동 생성 표현을 넣지 않습니다.

## 예정 섹션

- 제도의 의의
- 도입 배경
- 사모펀드 체계 개편
- 투자자 범위
- 자산운용 규제
- 주요 주체와 핵심 용어
- 시장 현황
- 연혁
